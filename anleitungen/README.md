# Anleitungen für Studierende (Projektwoche Maschinenbau, WS 2026/27)

Hier liegen alle Anleitungen, die Sie in der Projektwoche brauchen. Klicken Sie eine Datei an, um sie anzusehen,
oder laden Sie sie über das Download-Symbol rechts oben herunter.

| Datei | Wofür? | Wann? |
|---|---|---|
| `1_Aufbauanleitung_Auto.pdf` | Das Auto zusammenbauen: Motoren, Motortreiber, ESP32, Kabel. Erste Fahrt mit der App. | Tag 1 |
| `2_Programm_anpassen_und_flashen.pdf` | **Firmware selbst aufspielen** (flashen) und das Programm ändern: Dateien besorgen, Arduino IDE einrichten, ESP32 flashen, C++-Grundlagen, eigene Tasten in der App, Servo-Kicker | sobald das Auto fährt |
| `3_Aushang_App_QR-Code.pdf` | Kurzanleitung mit QR-Code zur App | zum Aufhängen |

## Wo ist die Firmware?

Die Firmware liegt in diesem Repository im Ordner [`firmware/RoboCar_BLE/`](../firmware/RoboCar_BLE/).
Am einfachsten laden Sie **alles auf einmal** herunter: auf der [Startseite des Projekts](https://github.com/stberman/robocar-steuerung)
den grünen Knopf **Code** ▸ **Download ZIP** klicken und die ZIP-Datei nach `C:\RoboCar` entpacken.
Ein GitHub-Konto brauchen Sie dafür nicht. Diese Anleitungen sind in der ZIP-Datei mit drin.

Wie es weitergeht, steht Schritt für Schritt in `2_Programm_anpassen_und_flashen.pdf`:
Kapitel 2 (Dateien besorgen), Kapitel 4 (Arduino IDE einrichten) und Kapitel 5 (ESP32 flashen).

Die App selbst müssen Sie nicht herunterladen: https://stberman.github.io/robocar-steuerung/
